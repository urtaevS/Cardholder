# 💳 Карты Лояльности

Telegram Mini App для хранения и управления картами лояльности магазинов прямо в мессенджере.

## 🎯 Основные возможности

### Управление картами
- **Добавление карт** — создавайте карты с названием магазина, номером штрихкода и выбором из 8 цветов
- **Сканирование штрихкодов** — используйте камеру телефона для автоматического считывания номеров (EAN-13, Code-128)
- **Просмотр и использование** — тап по карте открывает полноэкранный штрихкод для сканирования на кассе
- **Быстрое копирование** — коснитесь номера штрихкода, чтобы скопировать его в буфер обмена

### Организация
- **Режим редактирования** — изменяйте порядок карт стрелками вверх/вниз
- **Цветовая маркировка** — 8 цветовых схем для визуального разделения карт
- **Удаление с подтверждением** — двойная проверка предотвращает случайное удаление

### Синхронизация
- **Облачное хранилище** — автоматическое сохранение в Telegram Cloud (до 5 МБ)
- **Экспорт/Импорт** — перенос данных через JSON-формат
- **Локальное хранение** — карты доступны офлайн через localStorage

### Безопасность
- **Контроль доступа** — ограничение по Telegram ID
- **Приватные данные** — карты хранятся только на вашем устройстве и в Telegram Cloud

## 🚀 Быстрый старт

1. Откройте приложение через Telegram-бота
2. Нажмите **+** в верхней панели
3. Введите название магазина (например, "Пятёрочка")
4. Отсканируйте штрихкод или введите номер вручную
5. Выберите цвет карты
6. Готово! Карта появится в списке

## 💡 Подсказки

- Используйте разные цвета для категорий магазинов (продуктовые, одежда, аптеки)
- Включите режим редактирования для быстрой сортировки часто используемых карт наверх
- Регулярно сохраняйте данные в облако для безопасности

<summary>📋 Технические спецификации</summary>

### Стек технологий
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **API**: Telegram WebApp API
- **Библиотеки**:
  - jsQR — сканирование штрихкодов через камеру
  - JsBarcode — генерация изображений штрихкодов
  - Lucide Icons — иконки интерфейса

### Хранение данных
- localStorage (основное хранилище)
- Telegram Cloud Storage (резервное копирование)
- JSON-формат для экспорта/импорта

### Поддерживаемые форматы штрихкодов
- EAN-13 (стандарт для магазинов)
- Code-128 (универсальный формат)

### Развёртывание
1. Разместите файлы на веб-сервере с HTTPS
2. Создайте бота через [@BotFather](https://t.me/botfather)
3. Настройте Web App URL в настройках бота
4. Опционально: настройте ALLOWED_TELEGRAM_IDS в app.js

### Системные требования
- Telegram для iOS/Android/Desktop
- Браузер с поддержкой WebRTC (для сканирования)
- Минимум 5 МБ свободного места в Telegram Cloud
